# 🎮 Color Pulse: Mobile Game Production Case Study

## 📱 Project Overview
**Color Pulse** is a native Android mobile game that successfully completed the full production lifecycle—from initial conceptualization to global release on the **Google Play Store**. 

This repository serves as a **Product Management & Technical Case Study**, highlighting the SDLC (Software Development Life Cycle), feature prioritization, UI/UX design, and release management processes involved in shipping a commercial mobile product.

---

## 🚀 The Role: Solo Developer & Product Owner
As the sole creator of Color Pulse, I acted as both the Lead Engineer and the Product Manager. My responsibilities spanned across:
* **Product Strategy:** Defining the core gameplay loop and MVP feature scope.
* **UI/UX Design:** Prototyping custom, engaging user interfaces and smooth animations.
* **Development:** Writing clean, native code and integrating third-party SDKs.
* **Release Management:** Navigating the Google Play Console, handling App Store Optimization (ASO), and ensuring compliance with platform policies.

---

## 🛠 Technical & Production Stack
* **Platform:** Native Android 
* **Language:** Java
* **Analytics & LiveOps:** Firebase Integration (Crashlytics, User Engagement Tracking)
* **Design:** Custom UI/UX, intuitive game mechanics
* **Distribution:** Google Play Console

---

## 📈 Product Lifecycle & Milestones

### 1. Pre-Production & Planning
* Defined the target audience and core mechanic.
* Created wireframes and user flows for the main menu, gameplay loop, and game-over states.
* Prioritized the backlog to focus strictly on an MVP release to test market viability.

### 2. Active Development & QA
* Implemented the game engine logic using native Java.
* Conducted iterative playtesting sessions to balance the game's difficulty curve.
* Integrated **Firebase** to monitor application stability and track crucial user metrics post-launch.

### 3. Release & Post-Launch
* Managed the end-to-end publishing process via the **Google Play Store**.
* Prepared marketing assets (icons, screenshots, feature graphics).
* Monitored Firebase Crashlytics during the initial rollout phase to ensure a 99.9% crash-free rate.

---

## 💡 Key Takeaways for Project Management
Shipping *Color Pulse* provided invaluable hands-on experience in **Release Management**. It bridged the gap between writing code in an IDE and actually delivering a polished product to end-users, handling real-world challenges like platform constraints, SDK updates, and user retention tracking.
